# Google評判 総合コンサルパック（レビューブースト）

「悪い口コミを消す」のではなく「**評判を上げる**」を本命に据えた、Google評判改善・集客の**総合コンサルパッケージ**のLP＋提案書。

**公開URL**: https://removal-seven.vercel.app （口コミツール: https://removal-seven.vercel.app/review-tool ）
再デプロイ: `vercel --prod --token=<トークン> --yes`（`--token=`の後にスペースを入れない）

## サービスの考え方

- **「消す＝手段／評判を上げる＝ゴール」**。削除に頼らず、★評価・サジェスト・検索結果を含めたネット評判を総合的に改善し、長期的に「選ばれ続けるお店」をつくる。
- **月額サブスク型の総合パッケージ**が本体。買い切りではなく、契約期間中ずっと使える建て付け。
- **強み**：「LINE × 口コミ」の循環（来店→リピート→口コミ依頼／不満は口コミ前にLINEで拾う）。さらに**業種別にLINE導線をカスタム設計**（飲食店・クリニック・不動産・サロン等のビジネスケースをLPに掲載）。
- **口コミ獲得ツール**：タップ式の口コミ作成ツール（`review-tool.html`）＋ **NFC口コミカード**（kimito-link連携、かざすだけで起動）で投稿率を底上げ。

### 非弁行為（弁護士法72条）の回避 ← 重要

口コミ削除を有償で**代行**すると非弁リスクが高いため、**代行はしない**。役割を分担:

| 役割 | 内容 |
|---|---|
| 🤖 AI | 「違反の可能性」「申請文の書き方」を**ヒント提供** → **申請は事業者本人**が行う |
| ⚖️ 提携弁護士 | 権利侵害・悪質な誹謗中傷など**法的対応が必要な事案**を担当 |
| ⭐ 当社 | 口コミ獲得・MEO・WEB/LINE/アプリなど**評判改善の施策**に専念 |

LP・提案書とも「削除代行」という表現は使わず、「AIがサポート」「ご自身で申請」「結果は保証しない」旨を明記済み。（※一般的整理であり、最終的には弁護士確認を推奨）

## LPの確認方法

ビルド不要。`index.html` をブラウザで直接開くだけ。ローカルサーバーで見る場合：

```powershell
npx -y serve -l 4321 .
# → http://localhost:4321
```

LPの「口コミは、タップだけで完成。」セクションの「実際のツールを試す」ボタンから `review-tool.html` が開きます。

## 口コミ作成ツール（review-tool.html）

来店客にQRコード等で開いてもらい、質問にタップで答えるだけで自然な口コミ文章が生成され、コピー→Google投稿ページへ誘導します（投稿は本人・編集自由なので非弁の問題なし）。

**店舗ごとのカスタマイズ**は `review-tool.html` 内 `<script>` 冒頭の設定を変えるだけ：

```js
const STORE = {
  name: "矯正歯科クリニック",   // 店舗名
  color: "#2A7FBF",            // テーマカラー
  emoji: "🦷",                 // ロゴ代わりの絵文字
  reviewUrl: "https://search.google.com/local/writereview", // ←店舗のGoogle口コミ投稿URLに差し替え
};
```

質問・選択肢・生成される文面は同ファイルの `QUESTIONS` 配列で業種に合わせて編集できます。`reviewUrl` は店舗のGoogleマップ「クチコミを書く」リンクに差し替えてください。
